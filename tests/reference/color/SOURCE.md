# CIEDE2000 reference pairs

The 34 numeric pairs in `ciede2000.tsv` are the unmodified supplementary test data
published by Gaurav Sharma, Wencheng Wu and Edul N. Dalal for their 2005 paper,
*The CIEDE2000 Color-Difference Formula: Implementation Notes, Supplementary Test
Data, and Mathematical Observations*.

- [Author's reference page](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)
- [Original test data](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/dataNprograms/ciede2000testdata.txt)

The implementation is independently written from the mathematical formula; the
authors' MATLAB and Excel code is not included.
