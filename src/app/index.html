Playload

              
A tiny game engine that lets you share games as URLs


              
Specifications

              
    
                
  • Up to 3 KB of compressed JavaScript
    • 
                
  • API with 6 functions, 2 variables and 1 callback
    • 
                
  • 160 × 144 pixels, 8 colors, CRT display
    • 
                
  • Built-in 8 × 8 Unicode letters, symbols and emoji
    • 
                
  • ZX 128 PLAY-compatible, 3 sound channels
    • 
                
  • 4-direction and 2-button input (⬆ ⬇ ⬅ ➡ Ⓐ Ⓑ)
    • 
                
  • 
                  The URL’s payload is the whole game — Playable Payload...
                  Playload!
                
    • 
              

              

                Source code
              


              
Create and share

              

                

                  Write JavaScript code in the CODE editor and press
                  Run to execute it. Your code is stored in the URL, so you can
                  share it simply by sending the URL. To save your code, bookmark the URL.
                

                

                  Start your code with // @title My Title to set the title shown in
                  browser tabs and bookmarks.
